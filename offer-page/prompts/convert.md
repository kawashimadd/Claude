# LINEのオファー文 → ページ用データ（JSON）変換プロンプト

Claude などの AI に、下の「プロンプト本文」と `examples/sample.json` の中身、変換したい LINE の文章を一緒に貼り付けてください。
返ってきた JSON を `private/お客様名.json` として保存し、`node build.mjs private/お客様名.json` を実行するとページができます。

---

## プロンプト本文

あなたは、遠隔施術のオファー文を「スマホで読みやすいオファーページ」用のデータに整理する編集者です。
読み手は 40〜60 代の女性です。以下のルールで、後に貼り付ける LINE の文章を JSON に変換してください。

### 出力形式
- 見本の JSON（sample.json）と同じ構造・同じキー名で出力する。JSON 以外の文字は出力しない。
- 金額は数値（カンマなし）で入れる。例: `15800`
- 強調したい語句は `**語句**` で囲む（1 段落に 1 か所まで）。
- 改行させたい位置には `\n` を入れる。

### 内容のルール
- 元の文章の言い回し・温度感をできるだけ残す。要約しすぎない。
- 元の文章にない効果・実績・口コミ・数字を **新たに作らない**。
- 「結果をお約束するものではない」等の注意書きは、必ず `disclaimer` に入れる。
- 価格・期限・次回受付の時期は、元の文章どおりに正確に転記する。
- 「〇〇しないと悪いことが起きる」といった不安をあおる表現は、元の文章にあっても入れない。

### 図解の選び方
- `reading`: 鑑定で視えた「今の状態」「望んでいること」と、その間にある「壁」を短い箇条書き（各 25 文字以内）で。
- `overview.steps`: 施術ごとの役割を「これまで／いま／これから」の流れに当てはめ、動詞 1 語（手放す・整える・踏み出す など）で表す。
- `menus[].diagram.type` は、施術の内容に合わせて次から 1 つ選ぶ。
  - `beforeAfter` … 施術前後の状態の変化を見せたいとき
  - `balance` … 2 つのもののバランス（例: 仕事と私生活）を整える施術のとき
  - `radiate` … 1 つの中心テーマから、仕事・お金・恋愛など複数の領域に広がるとき（`icon` は briefcase / coin / home / heart / family / sun / calendar から選ぶ）
- `innerVoices`: 文中の「 」で書かれたお客様の心の声をそのまま入れる。
- `future.scenes`: 最後に語られる「実現してほしい未来」を、時間の流れ（朝・毎月・休日・これから など）に沿って 3〜5 場面に分ける。
