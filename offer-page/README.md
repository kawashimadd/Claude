# オファーページ生成ツール

LINE で送っている施術オファーの文章を、図解入りの 1 枚のページ（HTML）に変換するツールです。
読み手（40〜60 代の女性）がスマホで読みやすいよう、大きめの文字・広い行間・やわらかい配色にしています。

## 流れ

```
LINEの文章 ──(AIで整理)──▶ お客様ごとの JSON ──(build.mjs)──▶ オファーページ（HTML）
             prompts/convert.md          private/〇〇.json                dist/〇〇.html
```

1. `prompts/convert.md` のプロンプト・`examples/sample.json`・LINE の文章を AI に渡し、JSON を作る
2. `private/お客様名.json` として保存し、内容（特に金額・期限）を目で確認する
3. ページを生成する

   ```sh
   node offer-page/build.mjs offer-page/private/お客様名.json
   ```

4. `dist/お客様名.html` をブラウザで開いて確認し、公開先（ペライチ・STUDIO・自社サーバー等）にアップロードして URL を LINE で送る

Node.js 18 以上があれば動きます（追加インストール不要）。

## ページに入る図解

| 場所 | 図解 | 伝えたいこと |
| --- | --- | --- |
| 鑑定結果 | 今 →「壁」→ 望む暮らし | 今の悩みと本当の願い、その間にあるもの |
| 全体像 | 手放す → 整える → 踏み出す | 3 つの施術の役割分担（過去・今・未来） |
| 施術 ① | ビフォー → アフター | 施術で目指す心の状態 |
| 施術 ② | 天秤（偏り → 調和） | 「頑張る」と「楽しむ」のバランス |
| 施術 ③ | 中心テーマ → 仕事・収入・私生活 | 望む未来と、向き合う 3 つの領域 |
| 料金 | 表 ＋ 棒グラフ | 個別とセットの支払額の違い |
| 未来 | 朝 → 毎月 → 休日 → これから | 実現してほしい毎日のイメージ |

施術ごとの図解は JSON の `menus[].diagram.type` で `beforeAfter` / `balance` / `radiate` から選べます。

## 個人情報について

このリポジトリは **公開リポジトリ** です。お客様の名前や鑑定内容を含む JSON は `private/`、生成したページは `dist/` に置いてください。どちらも `.gitignore` 済みで、GitHub には上がりません。`examples/sample.json` は名前などを伏せた見本です。

生成したページには `noindex` を入れて検索エンジンに載らないようにしていますが、URL を知っている人は誰でも見られます。推測されにくい URL で公開してください。

## 公開前のチェック

- **二重価格表示（景品表示法）**: 「通常価格」は、実際にその価格で一定期間販売した実績がある金額にする。
- **特定商取引法に基づく表記**: ネットで有料サービスを申し込んでもらう場合、事業者名・連絡先・支払方法・キャンセル規定などの表記が必要です。
- **消費者契約法（霊感等による知見を用いた告知）**: 「受けないと悪いことが起きる」と不安をあおって契約させると、契約の取消し対象になります。注意書き（結果を約束しない旨）はページから外さないでください。
- 申し込みボタンの LINE の URL（`apply.button.url`）を入れると、緑のボタンが表示されます。空欄なら文章の案内だけになります。
